# 🏥 Hospital Management Dashboard

A professional and interactive **Hospital Management Dashboard** built using **Microsoft Power BI** to analyze hospital operations, patient information, billing, doctor performance, treatment costs, and patient satisfaction. The dashboard provides meaningful insights that help healthcare administrators make data-driven decisions.

---

## 📌 Project Overview

The Hospital Management Dashboard is designed to monitor and analyze key hospital metrics through an intuitive and visually appealing interface. It consolidates multiple datasets into a single dashboard, enabling users to track revenue, doctor fees, treatment costs, patient satisfaction, and admission types in real time.

This project demonstrates the use of **Power BI** for healthcare analytics by transforming raw hospital data into actionable business intelligence.

---

## 🚀 Features

* 📊 Interactive Power BI Dashboard
* 💰 Total Billing Analysis
* 👨‍⚕️ Doctor Fee Analysis
* 🏥 Treatment Cost Monitoring
* 😊 Patient Satisfaction Tracking
* 🌍 City-wise Revenue Analysis
* 🛏️ Room Type-wise Doctor Fee Distribution
* 🚑 Admission Type Analysis (Elective, Emergency, Urgent)
* 🩸 Blood Group-wise Patient Satisfaction
* 🎛️ Interactive Filters and Slicers

---

## 📈 Dashboard KPIs

| KPI                      | Description                                       |
| ------------------------ | ------------------------------------------------- |
| **Total Bill**           | Overall hospital revenue generated                |
| **Doctor Fee**           | Total consultation fees collected                 |
| **Treatment Cost**       | Overall treatment expenses                        |
| **Patient Satisfaction** | Satisfaction score categorized by blood group     |
| **City-wise Billing**    | Revenue generated from different cities           |
| **Room Type Analysis**   | Doctor fee distribution by room category          |
| **Admission Type**       | Distribution of treatment costs by admission type |
